# Original authors' dataset

Source: [HenokDanielbfg/5g-testbed-conference](https://github.com/HenokDanielbfg/5g-testbed-conference/tree/main/core%20dataset).

Selected folder: `core dataset/03 Feb 2025 - 18 Feb 2025`.
Pinned commit: `d6fae0dbd7cf70343201f9351fe60498b628bb86`.

Run `python download_data.py` to retrieve two original, unmodified files:

| File | Rows | Purpose |
|---|---:|---|
| df_location.csv | 652 | Timestamp, serving cell, device ID and tracking area |
| df_reg.csv | 915 | Registration state observations used to break mobility sequences |

`manifest.json` records source links and SHA-256 checksums. Raw downloads stay in
`data/raw/`, which is excluded from Git. No synthetic data is generated by the app.
Small fabricated fixtures in the tests are only for checking edge cases.

The upstream root did not expose an explicit dataset license when inspected.
The downloader lets users obtain data directly from its source; this project
does not grant rights over the authors' dataset or redistribute their full testbed.

## Important interpretation choices

- The source data was collected from a **simulated** Free5GC / UERANSIM testbed.
- Identifiers are strings; leading zeros are preserved. `imsi-` is removed only
  for matching registration identifiers to location identifiers.
- Dates are treated as source-local timestamps; no timezone is stated in the CSVs.
- Registration timestamps have coarser precision than location timestamps.
- Every recorded inactive state starts a new segment. Reports whose most recent
  known state is inactive are excluded. This conservatively excludes 268 of the
  652 location reports. It can discard genuine movements if the logs are not aligned.
- Before a device's first registration observation, its recorded locations are
  accepted without inferring its registration state.
- `duration_minutes` is never a feature or a boundary source: durations can
  contain information about the future and their semantics are not independently verified.
- Consecutive same-cell reports within a segment are collapsed. A cell change
  is an **observed within-session transition**, not protocol-level proof of handover.
- The next-cell target is derived within each device and segment. Rows without
  a previous cell or a later different cell cannot form labeled examples.

These decisions yield 384 visits, 160 within-session transitions, and 98 labeled
examples. The model predicts the next **different observed cell**, not the next
CSV row or the time until handover. Data preparation is intentionally narrower
than the paper's full experiment.
